### IQR outlier logic

For every numeric column:

```text
Q1 = 25th percentile
Q3 = 75th percentile

IQR = Q3 - Q1

lower bound = Q1 - 1.5 × IQR
upper bound = Q3 + 1.5 × IQR
```

A non-missing value is an outlier when:

```text
value < lower bound
OR
value > upper bound
```

No machine-learning or third-party outlier library is necessary.

## Edge cases

These will be intentional behavior, not accidental pandas behavior.

| Input | Expected behavior |
|---|---|
| Missing path | Clear error + nonzero exit |
| Directory | Clear error + nonzero exit |
| Zero-byte CSV | Clear error + nonzero exit |
| Unreadable/invalid CSV | Clear error instead of traceback |
| Header-only CSV | Valid report showing 0 rows |
| Text-only CSV | General report + numeric sections explicitly skipped |
| Constant numeric column | Valid summary; normally no IQR outliers |
| Numeric column with missing values | Ignore missing values for IQR calculations |
| All-missing numeric column | Handle gracefully; no crash |
| Duplicate rows | Count with `df.duplicated().sum()` |

For a text-only CSV, for example:

```text
Numeric Summary
---------------
Skipped: No numeric columns were found.

IQR Outliers
------------
Skipped: No numeric columns were found.
```

A header-only CSV should **not** be treated like a zero-byte file. Pandas can read the headers, so it is a valid dataset with shape such as:

```text
Rows: 0
Columns: 3
```

That distinction is important.
